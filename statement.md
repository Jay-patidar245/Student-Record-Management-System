# Project Statement

## Problem Statement
Maintaining student academic records manually can make searching, updating marks, and calculating results repetitive. This project provides a simple Python-based system to organize these operations in one place.

## Scope
The project covers basic student record management:
- Adding student records
- Searching records
- Updating marks
- Calculating total and percentage
- Displaying results
- Deleting records
- Saving records locally

The project is intended as a small academic management application and does not connect to a college ERP or online database.

## Target Users
- Students learning Python
- Teachers demonstrating basic record-management concepts
- Small academic demonstrations

## High-Level Features
1. Student registration
2. Student search
3. Marks management
4. Result calculation
5. Record display
6. Record deletion
7. Local JSON storage

## Functional Requirements
- The system shall allow a user to add a student.
- The system shall prevent duplicate student IDs.
- The system shall allow searching by ID or name.
- The system shall allow marks to be updated.
- The system shall calculate total and percentage.
- The system shall determine PASS/FAIL using the configured passing mark.
- The system shall display all records.
- The system shall delete a selected record.
- The system shall store records in a JSON file.

## Non-Functional Requirements
- Usability: menu-driven and easy to follow.
- Reliability: invalid inputs are handled with validation messages.
- Maintainability: functionality is divided into separate Python modules.
- Resource efficiency: the application uses a small local JSON file and standard Python libraries.

## Project Objective
The objective is to apply Python programming concepts such as classes, functions, conditions, loops, dictionaries, file handling, validation, and modular programming to a practical problem.
